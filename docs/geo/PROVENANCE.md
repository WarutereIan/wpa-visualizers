# Default choropleth map provenance

Static GeoJSON under `public/geo/` is generated by `npm run prepare:geo` (`scripts/prepare-geo.mjs`). Do not hand-edit the `.geojson` files; regenerate them from the script.

## World countries and Africa

- **Files:** `world-countries.geojson`, `africa-countries.geojson`
- **Source:** [Natural Earth](https://www.naturalearthdata.com/) 1:110m Admin-0 countries (GeoJSON from [nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector)).
- **Fallback:** vendored Redash map at `packages/redash-viz/src/visualizations/choropleth/maps/countries.geo.json` (also Natural Earth–derived) if the network fetch fails. Africa is then filtered by ISO country code.
- **License:** Public domain. Natural Earth data is in the public domain and may be used without restriction.
- **Attribution (optional, appreciated):** Made with Natural Earth. Free vector and raster map data @ naturalearthdata.com.

Africa is a subset of the world layer: features whose `continent` / `CONTINENT` is `Africa`, or whose ISO code is in the African ISO set used by the script.

## Kenya counties (ADM1) and sub-counties (ADM2)

- **Files:** `kenya-counties.geojson`, `kenya-subcounties.geojson`
- **Source:** [geoBoundaries](https://www.geoboundaries.org/) `gbOpen` release for Kenya, via:
  - https://www.geoboundaries.org/api/current/gbOpen/KEN/ADM1/
  - https://www.geoboundaries.org/api/current/gbOpen/KEN/ADM2/
- **Canonical names in the current release:** Counties (ADM1), Sub-Counties (ADM2).
- **License:** geoBoundaries Open (gbOpen) is licensed under [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/). You **must** give appropriate credit.
- **Suggested citation:** Runfola, D. et al. (2020) geoBoundaries: A global database of political administrative boundaries. *PLoS ONE* 15(4): e0231866. https://doi.org/10.1371/journal.pone.0231866
- **Source-data notes:** Individual geoBoundaries layers also record an upstream `boundaryLicense`. Kenya ADM1 source data is listed as public domain (RCMRD / Africa GeoPortal). Kenya ADM2 source data is listed as CC BY 3.0 IGO (IEBC / OCHA ROSEA via HDX). The files in this repo are redistributed as geoBoundaries gbOpen products and must be attributed accordingly.

## Processing

Geometries are simplified with [mapshaper](https://github.com/mbloch/mapshaper) (Visvalingam, `keep-shapes`) so Kenya ADM2 stays in a web-friendly size (target under ~2–3 MB). Feature `properties` are normalized so every feature has:

- `name` — human-readable label
- `code` — join key (ISO alpha-2 for countries; Kenya ADM1 uses ISO 3166-2 `shapeISO` when present, otherwise `shapeID`). **Kenya ADM2:** `shapeISO` is usually empty, so `code` is the opaque geoBoundaries `shapeID` — prefer joining on `name` for human sub-county labels unless your data uses shape IDs.

Original properties (`iso_a2`, `iso_a3`, `shapeName`, `shapeID`, `shapeGroup`, and Natural Earth fields when present) are retained.

See `public/geo/MANIFEST.json` for per-map `targetField`, `fieldNames`, source URL, and license.
